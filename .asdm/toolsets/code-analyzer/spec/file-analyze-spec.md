# 文件分析规范 Specification

## Language Guidelines

本规范定义的文档必须使用环境中检测到的响应语言。确保所有内容遵循：

1. **语言一致性**：在整个文档中使用相同的语言
2. **写作规范**：遵循检测到语言的写作风格和格式
3. **清晰性**：确保内容清晰易懂

**支持的语言**：
- 中文 (zh)
- 英文 (en)

---

## Overview

本规范定义了文件分析报告的结构和格式要求。此类文档用于分析指定目录下所有代码文件的大小、代码行数，并生成简洁的中文含义描述，帮助开发者快速了解代码库结构。

**主要用途**：
- 新项目接手时快速了解代码库结构
- 识别项目中的主要模块和职责
- 评估各代码文件的复杂度和规模
- 项目代码质量评估

## Section Guidelines

### 元信息 (Metadata)

报告开头应包含以下元信息：

- **分析路径**：被分析的目录路径
- **分析时间**：报告生成的时间戳，格式 `YYYY-MM-DD HH:mm:ss`
- **语言**：检测到的响应语言
- **总计**：文件数量、代码行数、文件总大小

### 统计概览

统计概览表格应包含：

- 总文件数：所有被分析的代码文件数量
- 总代码行数：所有文件的代码行数总和
- 总大小：所有文件的字节数总和（转换为 KB）
- 平均文件大小：总大小除以文件数
- 最大文件：代码行数最多的文件及其路径

### 语言分布

按编程语言统计文件分布：

- 统计每种语言的代码文件数量
- 计算各语言的代码行数
- 计算各语言的文件数占比和代码行数占比
- 按文件数或行数降序排列

### 文件详情

文件详情表格是报告的核心部分：

**字段说明**：

- 文件路径：相对于分析根目录的路径
- 代码行数：使用 `read_file` 统计的实际行数
- 文件大小：文件占用的字节数（转换为 KB）
- 含义描述：简洁的中文功能描述

**排序规则**：

- 默认按代码行数降序排列
- 大文件（>1000 行）应给予特别关注
- 描述应简洁明了，通常 1-2 句话

### 模块分布

按功能模块分组展示：

- 根据目录结构识别模块划分
- 每个模块包含：路径、文件数、代码行数、功能描述
- 模块应按总代码行数降序排列

## Usage Guidelines

生成文件分析报告时：

1. **步骤 1**：接收用户提供的分析路径参数
2. **步骤 2**：验证路径有效性
3. **步骤 3**：扫描目录并识别代码文件
4. **步骤 4**：分析每个文件的统计信息
5. **步骤 5**：生成中文含义描述
6. **步骤 6**：排序和组织结果
7. **步骤 7**：生成 Markdown 格式报告
8. **步骤 8**：保存报告到指定目录

**重要提示**：

- 优先分析核心目录（如 src、app、lib 等）
- 跳过构建产物目录（如 node_modules、dist、build）
- 对大文件（>1000 行）给予特别关注
- 描述应简洁明了，通常 1-2 句话

## Output Format

文件分析报告应按以下格式输出：

**格式**: Markdown
**位置**: `.asdm/workspace/code-analyzer/analysis-reports/file-analysis/`
**命名**: `<timestamp>-file-analysis.md`

**格式详情**：

- 使用标准 Markdown 语法
- 表格使用 GitHub Flavored Markdown 格式
- 时间戳格式：`YYYYMMDD-HHMMSS`
- 文件大小保留 2 位小数（KB）

**示例**：

- 输出路径：`.asdm/workspace/code-analyzer/analysis-reports/file-analysis/20260409-101430-file-analysis.md`
- 命名格式：`YYYYMMDD-HHMMSS-file-analysis.md`

## Best Practices

处理文件分析时：

1. **渐进式分析**：先分析顶层目录，再按需深入子目录
2. **准确统计**：使用实际读取文件的方式统计行数
3. **语义描述**：从路径和文件名推断功能，使用项目通用术语
4. **排除规则**：默认排除 node_modules、dist、build、__pycache__ 等

### Common Pitfalls to Avoid

- **路径错误**：未验证路径是否存在就开始分析
- **遗漏文件**：未正确处理隐藏文件或特殊命名文件
- **描述模糊**：生成过于笼统或过于具体的描述
- **统计错误**：文件大小单位不统一或计算错误
