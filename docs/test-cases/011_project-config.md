# 用例名称： 项目设置
本用例适用于用户在项目中进行项目设置
## 操作步骤
1. 用户进入 ASDM管理后台 首页
2. 点击项目列表中 "测试组织0101-项目01" 项目名称, 进入项目页面
3. 右侧工作区打开 项目设置 页面
4. 点击 [其他] Tab页签
5. 点击 [+添加仓库配置] 按钮
6. 打开 [添加仓库配置] 窗口
7. [添加仓库配置] 信息录入
   仓库类型： 选择 [github]
   鉴权方式： 选择 [Token]
   仓库URL： "https://github.com/meigx2013/Ai-Fast"
   仓库分支： develop
   仓库Token： "ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
8. 点击 [保存] 按钮
9. 仓库配置列表中增加一条记录
10. 点击新增的仓库配置记录右侧的 [检测可用性]
11. 返回检测成功 
## 预期结果
1. 仓库配置列表中增加一条记录
2. 检测可用性成功
## 前置条件
1. 用户：test01@asdm.ai, 已完成系统登录
2. 项目 "测试组织0101-项目01" 已创建
3. 进入 "测试组织0101-项目01" 项目页面
