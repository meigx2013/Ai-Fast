# 用例名称： 创建令牌
本用例适用于用户进行PAT令牌创建
## 操作步骤
1. 用户进入 ASDM管理后台 首页
2. 点击右上角 登录用户信息 区域
3. 弹出窗口, 点击 [访问令牌] 链接
4. 进入用户资料页面，[访问令牌] Tab页签
4. 点击 [创建令牌]
5. 打开 [创建个人访问令牌] 窗口
   令牌名称： "asdm-pat"
   有效期： 选择[30天] 
   点击 [创建] 按钮
   [复制] 生成的令牌(令牌格式如：pat_TTYseGwXUHU8OE5H3T7s1ye_vyE4eYbQU9nU_wl5cSE)
## 预期结果
1. 令牌生成成功
## 前置条件
1. 用户已完成系统登录
