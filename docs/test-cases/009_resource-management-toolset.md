# 用例名称： 资源管理
本用例适用于管理员进行平台级资源管理
## 操作步骤
1. 用户进入 ASDM管理后台 首页
2. 点击左下角 [平台级设置] 按钮
3. 右侧工作区打开 平台级设置 页面
4. 点击 [资源管理] Tab页签
5. 点击 [+ 上传资源] 按钮, 打开 [上传资源] 窗口
6. [上传资源] 数据录入
   上传范围： 选择[全局]
   资源类型： 选择 [场景智能体]
   选择上传文件： 点击选择文件, 打开我的电脑, 目录：D:\\TEST01\\toolset
   选择一款场景智能体（如：basic-tools-v2.zip）进行上传
   名称：获取上传文件名称
   描述： 获取上传文件名称
   唯一ID：默认值
   版本： 默认值
   分类： 选择[研发主流程]
   点击 [上传] 按钮
## 预期结果
1. 资源管理列表中增加一条记录
## 前置条件
1. 用户已完成系统登录
2. 打开目录中存在一款场景智能体（如：basic-tools-v2.zip）
