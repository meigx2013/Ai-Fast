# 用例名称： 创建新项目
本用例适用于用户进行新项目创建
## 操作步骤
1. 用户邮箱: test01@asdm.ai 密码: admin@2026 完成系统登录
2. 用户进入 ASDM管理后台 首页
3. 右侧工作区, 点击顶部 [组织与项目] 导航; 打开 [组织与项目] 导航窗口
4. 组织层级树中，点击 "测试组织0101" 节点
5. 点击 项目列表 上面的 [+新建项目] 按钮
6. 打开 [新建项目] 窗口
7. [新建项目] 信息录入
   项目名称： "测试组织0101-项目01"
   点击 [创建项目] 按钮
## 预期结果
1. 项目列表中增加一条记录 "测试组织0101-项目01"
## 前置条件
1. 用户已完成系统登录
2. 已创建组织 "测试组织0101"
3. 已创建用户 "test01@asdm.ai"
