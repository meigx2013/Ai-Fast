# 开发贪吃蛇游戏完整版
角色：你是一名资深前端工程师，擅长写简洁、可维护的小游戏代码。

任务：开发一款简易贪吃蛇游戏，输出为单个 HTML 文件（HTML/CSS/JS 内联），双击即可在浏览器运行，不依赖任何外部库或网络资源。

## 核心玩法

1. 蛇在网格画布上移动，吃到食物身体变长、得分增加。

2. 撞到墙壁或撞到自己身体 → 游戏结束。

3. 食物随机生成在空白格子，不能与蛇身重叠。

## 操作与交互

1. 方向键（↑↓←→）控制方向；禁止 180° 反向（如正在向右时不能直接向左）。

2. 空格键暂停/继续。

3. 游戏结束后显示"Game Over"和最终得分，提供"重新开始"按钮（或按 R 键重开）。

## 视觉要求

1. 画布用 Canvas 实现，网格清晰（建议 20×20 格，每格 20px，可自行调整）。

2. 蛇头与蛇身颜色区分，食物用醒目颜色（如红色圆点）。

3. 页面顶部显示当前分数和最高分（最高分用 localStorage 保存）。

## 代码质量要求

使用 requestAnimationFrame 或 setInterval 驱动游戏循环，速度可配置（如初始 150ms/步）。

逻辑分层清晰：初始化、输入处理、更新状态、渲染分离，关键函数加注释。

变量命名语义化，避免全局变量污染（可用模块化 IIFE 或简单对象封装）。

处理边界情况：游戏结束后忽略方向键输入、暂停时蛇不移动。

## 输出

1. 输出完整的代码, 保存到 `snake` 目录下
